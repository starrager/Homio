## 📋 О проекте

**Homio** — это платформа, которая помогает быстро решать бытовые проблемы без лишних звонков и поисков мастера. Просто выберите услугу, укажите время и адрес — всё остальное мы берём на себя.

**Как это работает:**

1. Выбираете категорию и услугу
2. Указываете адрес, дату и время
3. Описываете проблему
4. Отправляете заявку
5. Получаете подтверждение
6. Отслеживаете статус заказа

**Почему Homio:**

- ❌ Не нужно искать мастера
- ❌ Не нужно звонить и договариваться
- ✅ Одна заявка — и проблема решена

## ✨ Возможности

### 🔐 Авторизация
- Регистрация и вход
- JWT-авторизация
- Хеширование паролей (bcrypt)
- Защищённые роуты

### 📋 Услуги
- Категории: Уборка, Починить, Электрика, Сантехника, Сборка, Другое
- Динамический список услуг в каждой категории
- Расчёт ориентировочной стоимости

### 📦 Заказы
- Создание заказа с адресом, датой и временем
- Автоматическое обновление статусов:  
  `NEW` → `IN_PROGRESS` (когда наступает время)  
  `IN_PROGRESS` → `COMPLETED` (через 2 часа)
- История статусов
- Просмотр всех заказов в личном кабинете

### 👤 Профиль
- Редактирование имени, фамилии, email, телефона, адреса
- Смена пароля
- Настройка уведомлений

### 🛠️ Админ-панель
- Просмотр всех заказов
- Изменение статусов
- Управление услугами

## 🧱 Технологии

### Backend
| Технология | Назначение |
|------------|------------|
| Node.js + Express | Серверная логика |
| TypeScript | Типизация |
| Prisma ORM | Работа с БД |
| SQLite | База данных |
| JWT | Авторизация |
| bcrypt | Хеширование паролей |
| node-cron | Автоматическое обновление статусов |

### Frontend
| Технология | Назначение |
|------------|------------|
| Vue 3 (Composition API) | UI фреймворк |
| Pinia | Управление состоянием |
| Vue Router | Навигация |
| Axios | HTTP-запросы |

### Инфраструктура
| Технология | Назначение |
|------------|------------|
| Docker | Контейнеризация |
| Render | Деплой бекенда |
| Vercel | Деплой фронтенда |

## 🚀 Локальный запуск

### 1. Backend

```bash
cd backend
npm install
npx prisma generate
npx prisma migrate dev --name init
npm run dev

Сервер запустится на http://localhost:5178

2. Frontend
bash
cd frontend
npm install
npm run dev
Приложение будет доступно на http://localhost:5173

3. Сборка для продакшена
bash
# Бекенд
cd backend
npm run build

# Фронтенд
cd frontend
npm run build
📝 API Документация
После запуска бекенда документация Swagger доступна по адресу:
http://localhost:5178/api-docs
